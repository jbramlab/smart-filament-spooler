Individual Project · Smart Filament Spooler

How the spooler works

The filament path, the electronics, what happens during a run, and the tension control loop. The whole build stays under £100, including the later targets.

  • 1.75 mm filament
  • PLA ≈ 2.86 g/m (label: 1 kg = 350 m)
  • 3:1 printed gear
  • Splice pass < 1.85 mm
  • ≈ £98 UK retail

1Filament path

Filament runs left to right. Each stage has one job.

flowchart LR
  SRC["Source spool
hall sensor counts turns"] --> BRK["Servo brake
sets back-tension, clamps on snap"]
  BRK --> RUN["Runout switch
detects end or snap"]
  RUN --> DAN["Dancer arm
angle = tension"]
  DAN --> WHL["Measuring wheel
AS5600 counts metres"]
  WHL --> SPL["Splicer
heated PTFE tube"]
  SPL --> TRV["Traverse guide
1.75 mm per spool turn"]
  TRV --> RCV["Receiving spool
NEMA 17 + 3:1 gear"]

2Electronics

The ESP32 reads every sensor and drives every actuator. The touchscreen is how people control it.

flowchart LR
  subgraph IN["Sensors"]

    S2["Hall sensor on source spool"]
    S3["Dancer arm potentiometer"]
    S4["AS5600 measuring wheel"]
    S5["Splicer thermistor"]
    S6["Traverse endstop"]
  end
  subgraph OUT["Actuators"]
    direction TB
    A1["NEMA 17 via TMC2209

    A2["28BYJ-48 via ULN2003
traverse"]
    A3["Servo
tension brake"]
    A4["Heater + fan via MOSFET
splicer"]
  end
  IN --> ESP["ESP32"]
  ESP --> OUT
  TS["2.8 inch touchscreen
LVGL UI"] <--> ESP
  PSU["12 V 5 A supply
+ 5 V converter"] -.-> ESP

3What happens during a run

The machine checks for slip, snaps and the end of the spool on every loop, and reacts on its own.

flowchart TD
  P(["Power on"]) --> M["Pick material on touchscreen
sets tension, grams per metre, splice temp"]
  M --> S["Spool setup
core size and width"]
  S --> T["Thread filament, press Start"]
  T --> W["Winding
motor winds, traverse lays rows, PID holds tension"]
  W --> C{"Checks every loop"}
  C -->|"All OK"| U["Update screen
metres, grams, metres left"]
  U --> W
  C -->|"Motor and wheel disagree,
or stall detected"| SL["Pause, show Slip warning"]
  SL --> RS["User fixes it, presses Resume"]
  RS --> W
  C -->|"Switch opens or
dancer goes slack"| Q{"Source spool
nearly empty?"}
  Q -->|"No: snapped"| B["Stop motor, clamp brake
both spools held"]
  B --> SP["Splice wizard
cut square, insert, heat, cool"]
  SP --> CK{"Joint under 1.85 mm?"}
  CK -->|"Yes"| W
  CK -->|"No"| SP
  Q -->|"Yes: end of spool"| E["Wind remaining distance
minus a few cm, then hold"]
  E --> F["Prompt: clip end into flange hole"]
  F --> D(["Done: total metres and grams"])

4Tension control loop

A feedback loop, the same idea as in Systems and Control. The target tension changes with the material picked.

flowchart LR
  SP["Target tension
from material"] --> CMP(("compare"))
  CMP -->|"error"| PID["PID controller
on ESP32"]
  PID --> SV["Servo brake force"]
  SV --> TEN["Filament tension"]
  TEN --> DA["Dancer arm angle
potentiometer"]
  DA -->|"measured tension"| CMP
Build order: core winder, then sensors, then touchscreen, then tension control, then splicer. After step 3 you already have a working smart spooler.
